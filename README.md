## Engineering approach

I prefer infrastructure that is:

- **observable** before it becomes critical
- **automated** instead of manually repeated
- **documented** so operations do not depend on tribal knowledge
- **reproducible** across environments
- **secure by default**, especially around credentials and privileged access
- **simple to operate** when something fails at 3 AM

I use GitHub to publish sanitized, reproducible versions of real infrastructure patterns and projects, without exposing production data, credentials or internal company information.
